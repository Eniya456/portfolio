# Resume Placeholder

Place your resume PDF here as: `Eniya_V_Resume.pdf`

This file should be placed in the `public/` directory of the project.
The Resume download buttons in the portfolio point to `/Eniya_V_Resume.pdf`.

To add your resume:
1. Obtain your latest resume PDF
2. Name it exactly: `Eniya_V_Resume.pdf`
3. Place it in this `public/` folder
4. The download buttons will work automatically
